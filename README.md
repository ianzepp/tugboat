# Tugboat

Tugboat has moved into the [Vivi](https://github.com/ianzepp/vivi) repository.
The protocol is a skill that runs on a Vivi backlog, so it now ships with the
CLI it depends on:

| Skill | Where |
| --- | --- |
| Tugboat: a Mind routes, Hands implement, Auditors and Heads review, Cadence advises | [`skills/tugboat`](https://github.com/ianzepp/vivi/tree/main/skills/tugboat) |
| Speedboat: the fast alternative, small parallel Hands and minimum verification | [`skills/speedboat`](https://github.com/ianzepp/vivi/tree/main/skills/speedboat) |
| Vivi: the CLI both run on | [`skills/vivi`](https://github.com/ianzepp/vivi/tree/main/skills/vivi) |

To install, clone `ianzepp/vivi` and symlink the skill folders you want into a
client skill directory; its README, "Agent skills", has the loop.

This repository keeps the history of the protocol up to the move. It no longer
carries the protocol, the charters, or the scripts, and nothing here should be
installed.
